# creatinepedia

> **Status: archived 2026.07.25.** Kept public as a historical artifact. No maintenance, no support.

An experimental static encyclopedia of creatine research. Entries link to sources for readers to inspect; the repository does not claim that every statement has been independently peer reviewed.

Medical disclaimer: This project is for general education, not medical advice. Talk with a qualified clinician before changing supplements, especially if you have a medical condition, take medication, are pregnant, or are under 18.
